**1. Werkzeuge installieren**

- Node.js 20 oder neuer: https://nodejs.org (prüfen mit `node --version`)
- Git (unter Windows „Git for Windows“): https://git-scm.com
- Optional: VS Code mit der Extension „Claude Code“

**2. Claude Code installieren**

macOS / Linux / WSL:

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

Windows (PowerShell):

```powershell
irm https://claude.ai/install.ps1 | iex
```

Danach ein neues Terminal öffnen und prüfen: `claude --version`

**3. Einmal anmelden**

Im Terminal `claude` eingeben. Es öffnet sich der Login im Browser. Meldet euch an mit [eurem Firmen-Claude-Konto / dem Zugang, den ihr von uns bekommen habt]. Wenn „Welcome to Claude Code“ erscheint, seid ihr fertig; beenden mit `/exit`.
